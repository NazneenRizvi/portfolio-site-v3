## Local development

```bash
npm ci
npm run dev
npm run build
```

## Contact form setup

Configure environment variables on the hosting provider:

- `RESEND_API_KEY` — secret key from Resend.
- `CONTACT_FROM_EMAIL` — verified domain sender approved by Resend.
- `NEXT_PUBLIC_SITE_URL` — final deployed website URL.

Until configured, form submission displays an error and provides the public email address as a fallback. No fake success message.
